# Diario peso

Web app (PWA) per tracciare il peso e seguire il piano kcal/macro della stagione. Salva i dati solo sul dispositivo.

## Uso
Apri l'indirizzo di GitHub Pages dal telefono, poi in Safari: Condividi -> Aggiungi alla schermata Home. Usa sempre l'icona.

## Sviluppo
`python3 -m http.server 8000` e apri http://localhost:8000. Vedi `CLAUDE.md` per regole e contesto.
